# 🛍️ Customer Behavior Analysis

## 📌 Project Overview

Customer Behavior Analysis is a complete end-to-end Data Analytics project designed to understand customer purchasing behavior, demographics, spending habits, and product preferences. The project follows the full analytics lifecycle, from data collection and preprocessing to exploratory data analysis (EDA), visualization, and interactive dashboard creation.

---

## 🎯 Objectives

* Understand customer purchasing behavior.
* Segment customers based on demographics and spending.
* Identify high-value customers.
* Analyze sales and revenue trends.
* Generate business insights for customer retention and marketing strategies.
